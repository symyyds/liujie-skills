# 精读笔记内容标准

本标准要求摘要完整翻译，并以连贯的中文解释方法、图表和实验，让读者准确理解论文及科研价值。按内容需要决定篇幅，不统一限制字数、页数或图数。

## 原文证据

完整精读通读全文后再写；局部翻译、读图或修订任务读取完整相关页、必要上下文与核验位置，只完成所指定内容，以下六章标准按涉及部分应用。对摘要、关键机制、主要结果和局限逐项回查；必要时读附录、实验配置和图表脚注。每个事实段与图保留所读 PDF 的物理页码及章节/图表编号；区分 PDF 页码和印刷页码。作者没有报告的内容写明未报告，不能凭方法名称补出流程或实验设置。

每篇内部保留摘要逐句对齐、事实来源和核查记录：实际阅读章节、核对的关键数字、版本差异/歧义及处理结果。机械检查不能替代逐句翻译核对和逐图查看。

## 六章及完成标准

### 摘要

- 只翻译所读版本的 Abstract；先确认摘要起止，避免把引言、关键词或出版信息并入。
- 从头到尾完整对应原文，保持原顺序、段落、信息、数值、单位、比较对象、最大/平均/可能等限定及作者口吻。只清理 PDF 排版换行、断词等提取噪声。
- “一个字不差”的实际目标是忠实完整，不是生硬逐词替换。中文可调整局部语序以自然表达，但不得删句、概述、加强结论或添加解释。
- 原文与中文保存到 `abstract_alignment/ID.json`，译文逐句对应。Word 中组成正常段落，不额外把双语对照表塞进模板。
- 原摘要即使有疑似错误、与正文矛盾或过强表述，也先忠实翻译；在结果或总结说明差异。不能静默改数字、用官网摘要替换 PDF 摘要，或将项目建议写入摘要。

完成标准：对照原页和逐句记录，全部句子与信息都在，没有新增评论，Word 译文与核对稿一致。

### 贡献

先说明作者解决的具体问题和已有方法为何不足，再讲本篇做了什么、交付什么新方法/数据/工具/证据、价值体现在哪里。保留作者对新颖性的限定。用连贯说明组织贡献，缩写在首次出现时解释。

完成标准：读者能够说清研究问题、此前障碍和本篇新增内容，而不是只能复述贡献列表。

### 关键技术（实现方法）

沿输入 → 关键步骤 → 输出说明数据或程序如何变化，每个关键步骤解释目的、操作和下游用途。覆盖论文实际报告的核心算法、模块分工、训练/筛选/验证机制；必要公式解释变量和直观含义。用原文中的例子走通机制；自拟教学例子须明确标识且不能充当实验事实。

把方法图放在对应机制旁，避免先堆整页术语再插一幅无人解释的图。工具调用、智能体角色、反馈循环、样本过滤等应说明连接关系与终止/接受条件（原文有报告时）。

完成标准：读者理解“怎么做”和“为什么如此设计”，能够复述主要流程及关键选择；未报告的细节仍保持未知。

### 实验设计

按研究问题讲解每组实验为什么做、怎样检验方法。交代相关数据来源与规模、语言/CWE、标签或真值依据、训练/验证/测试划分、基线及比较公平性、指标定义与方向、关键设置、消融与成本。只列与论文有关且有证据的项目，不将每篇硬套成训练实验。

漏洞研究尤其区分：检测器不报警、通过功能测试、动态触发漏洞、人工确认和真实可利用性；这些是不同的证据。写清评价单位是函数、提交、仓库、CVE 还是执行任务。

完成标准：读者知道每组实验回答什么问题、比较谁、如何测量，以及设置如何支撑该问题。

### 实验结果对比

围绕前述研究问题解释主结果、关键对照、消融、泛化、失败案例与成本。选有代表性的数字和原图表，说明变化幅度与意义、有效条件和未胜出的情况。

逐项核对行列、指标高低方向、样本量、分母与单位；区分百分点、相对提升、绝对数与比例。必要时显示计算依据。跨不同数据集、划分或指标的分数不能直接排名。作者报告与读者计算分开，保留影响理解的表文冲突与统计口径差异。

完成标准：结果与实验问题对应，读者知道效果来自哪个条件、证据支持到哪里，不被“整体最优”掩盖例外。

### 总结

用自然段串起论文支持的核心结论、关键不足和对用户课题的启发。

- 不足区分“作者指出”“从实验设计可见”“阅读判断/待验证”。缺少报告不自动等于已证实缺陷，推断必须解释依据。
- 科研启发落到可借鉴的具体机制、变量、数据构造/清洗方式、验证方法或对照实验，并说明适用前提。可提出一个小规模可检验的下一步，但不自动运行实验。
- 当前课题涉及漏洞检测时，可联系“漏洞特征 → 可信样本 → 检测改善”，也可以解释论文只服务其中哪一步；关联较弱时如实说明，不强行把所有工作解释成数据生成。

完成标准：读者获得明确结论、边界和可尝试的研究动作，能够区分论文事实与笔记作者建议。

## 每幅原图和表格的解释

直接查看原图及附近正文，保留图号、完整图例/表头/关键脚注和必要原图注。不能只根据图片文件名或提取的正文猜图。

- 流程/框架图：解释模块、输入输出、箭头、阅读顺序及一次数据如何走过流程。
- 结果图/表：解释行列/坐标/单位/面板/图例，选一处具体对照或趋势说明含义，联系该实验问题。
- 局部放大图：明确是原图/原表局部，只解释该区域；整体和局部相互对应，不重复整段解说。
- 不把图题改写一遍当解读，也不逐格抄表。方位、箭头方向、颜色对应关系和数值均需回看图像验证。

原图裁切清晰且文字可读。先保留整体，确需放大时再加局部；缩放不改变纵横比、不丢图例/数据/注释。原文无相应图表时用文字说明，不虚构“原图”。

## 中文阅读感

用具体、连贯的中文解释因果和机制；必要术语首次解释后保持一致。重点通过段落组织体现，长方法可加少量小标题，不把所有段落改成密集清单。

删去不传递信息的口号和机械过渡，例如重复的“赋能、构建闭环、具有重要意义”。保留必要边界说明，放在相应结果或局限处，不给每幅图都加同一句免责声明。完成后通读一遍：只看笔记也能理解方法和实验，再对照原文确认没有为流畅而改变含义。
