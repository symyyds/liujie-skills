# 检索与下载

## 检索与筛选

- 将研究问题拆成主题词、方法词与评估词，使用中文和英文组合。漏洞检测课题的示例词可覆盖漏洞特征/检测失效、标签噪声/可信样本、漏洞注入/数据增强、多智能体验证、跨项目检测/真实代码评估。按论文实质与课题关联筛选，不靠标题包含 LLM 或 vulnerability 就纳入。
- 优先会议/期刊官网、出版社 DOI 页面、作者主页、官方项目页和可信预印本库。搜索摘要用于候选发现，精读内容以正确全文为准。通过参考文献和引用关系补齐重要工作；记录检索日期、范围和来源。
- “近一年”按本次日期重新计算。分别记录正式发表日期、首次公开日期与所读版本；会议举行日、接收日、DOI 创建日及未来卷期日期各有含义。纳入依据明确，不能把未来举行的会议称为已经举行。
- 用户未指定等级时，可优先筛选 CCF A/B 或中科院 1/2 区，并在检索前说明；用户当前指定的标准优先。核验对应年份/版本、会议全称、期刊名及轨道。CCF 等级与中科院分区分列或清楚标注体系；JCR Q1 不能代替中科院 1 区。无法核验就写“未核验”，记录来源限制；不能沿用旧批次分级镜像的结论作为当前事实。
- 正式论文、已接收稿、预印本与技术报告明确区分。重要的非优先级别论文可作为补充并解释价值，不能伪装成已发表高等级论文。
- 用 DOI、arXiv ID、题名、作者和版本去重。预印本与正式版通常合为一项，保存版本关系；同一简称对应不同论文时逐篇验证。

## 文献 Excel

必要列：论文名字、期刊/会议、等级、原文链接。原文链接使用可点击的 DOI/官方论文入口，开放 PDF 链接可另列。

为后续精读建议补充：论文 ID、日期/纳入依据、与课题关联、发表状态、全文来源与本地路径、阅读状态。大段内容留在笔记中，Excel 保持可筛选、易浏览。等级标明体系与核验依据；分级说明可集中在说明工作表。

文献信息和链接逐项核查；格式与有效超链接通过当前 spreadsheets skill 验证。已有用户文献表直接续接，不另造一套冲突编号。

## 下载与身份核验

1. 优先出版社开放全文、作者公开稿、机构仓库、会议附件或 arXiv。正常下载属于该流程，不必逐篇再次询问。受访问限制时尝试其他合法公开来源，记录失败原因；不把登录页、验证码或错误页当 PDF。
2. 文件保存在本批次 `sources/`，使用稳定 ID 加简短题名。保留原文，另存按 PDF 物理页分隔的提取文本。下载记录包括源 URL、取得日期、版本、文件名和 SHA-256；新版本另存，不覆盖未核对旧稿。
3. 同时检查 PDF 文件头/解析结果、页数、首页题名、作者和 DOI/arXiv 标识；正文含相关方法与实验。仅能打开文件不代表下载了正确论文。同名文件、错误 DOI 和搜索引擎重定向均需检查。
4. 扫描 PDF 需要 OCR 时，关键摘要、公式、图表和数字回看页面；自动提取的断词、分栏错序和字符误识别不能直接成为翻译依据。
5. 全文不可得时列出缺失 ID、题名、原文入口、已尝试来源/问题和建议文件名，创建明确的 `待补全文/` 目录。继续完成其他论文；完整批次交付前如仍缺失，准确说明范围。收到用户补充文件后重做身份核验再继续精读。

阶段完成标准：所有纳入项均有可追踪的正式信息和全文状态；每个“可精读”项实际绑定了经身份核验的可读 PDF。找论文阶段的摘要级内容不能冒充后续全文精读。
