# 忠实翻译与段落逻辑

## 来源与覆盖

用户上传的正式版本优先于旧稿和在线版本。只有用户要求查证，或当前来源确实缺失且获得相应指示时，才额外找材料；补充信息不能无标记混进翻译。

先列出可观察的结构和数量，再进行全文翻译。PDF 提取时同时保留页图及坐标，检查双栏顺序、连字符断词、跨页句子、页眉页脚、脚注与表题。恢复断词要区分排版软连字符和有意义的技术连字符；负号、范围号、数学符号不能一起清理。扫描页需要 OCR 与图像复核，不可把无法识别的段落当空白。

源块 ID 是追溯工具，不是对用户展示的正文。例如 `p003-b007` 表示第 3 页某块，跨页段落可以映射多个 ID。显式列出 ID；不要把只有两个元素的列表猜成“首尾闭区间”。新插入的译注单独标记，不能假装有原文来源。

非内容排除需要有依据。重复页眉、页码和编辑系统行号可以排除，页顶的真实表题不可以。附录、作者贡献、致谢、数据声明、脚注和参考文献属于全文的一部分；不适用的部分自然不存在，不强行补齐。

## 术语表与跨段一致性

术语表按本篇文章建立，建议记录英文、首选中文、缩写、定义所在位置、容易混淆的近邻概念。翻译前先定高频概念；遇到上下文改变含义时明确修订，并检查前文。

不要为了“中文化”消灭方法名、变量名、代码标识、数据集名称、命令参数或学界通用缩写。第一次出现可以写“中文（英文，缩写）”，后文使用统一简称；不是所有普通词都需要括号英文。

同形词不能跨领域套用一份永恒词典。比如 profile 可能是建模、配置或剖面；由论文的操作与定义决定，不由词面决定。

## 段落处理方法

在内部用一句话说明该段功能，再译成连贯中文；不要把功能标签写进正文。

1. 识别该段的中心陈述及其条件。
2. 梳理事实、解释、对照、推论、例外之间的关系。
3. 确认句中 this、these、it、the former、such 等的先行词。
4. 按中文表达重排句内成分，必要时拆分长句，保持逻辑段落的次序与边界。
5. 连读前后段：是否接得上，是否引入了尚未定义的对象，是否让一个局部结果看起来支持了全文结论。

可以把隐含但唯一明确的指代译成具体名词，例如把“这一结果”写为“这一误差下降”；只有源文能够唯一确定时才这样做。逻辑含糊时保留含糊并记录疑点，不添加未经支持的因果词。

## 高风险语义对照

下面是自拟例子，不代表某篇真实论文的结果。

| 原文含义 | 应保留的表达 | 不应替换为 |
| --- | --- | --- |
| The error fell from 12% to 9% under the fixed budget. | 在固定预算下，误差从 12% 降至 9%。 | 误差下降了 9%；在所有预算下都更好。 |
| This suggests improved stability, but does not establish the mechanism. | 这提示稳定性有所改善，但并未确定其机制。 | 这证明了该机制。 |
| No significant difference was detected. | 未检测到显著差异。 | 两者完全相同。 |
| Only the held-out set was used for evaluation. | 评估仅使用留出集。 | 使用测试集训练与评估。 |
| A outperformed B only when the sample size exceeded 100. | 仅当样本量超过 100 时，A 的表现优于 B。 | A 优于 B。 |
| The gain is associated with the full objective rather than one component alone. | 该增益与完整目标有关，不能仅归于其中一个分量。 | 单一分量产生了全部增益。 |

保留至少这些维度：谁/什么、何时、在哪个数据集/设备/设置下、相对于谁、采用何种指标、数值与单位、样本量、阈值、统计方法、是否为观察或推断、结论是否允许外推。

## 翻译和编辑的边界

可改：语序、长句拆分、必要的名词回指、中文标点、非语义性断词与 PDF 换行。

不可擅改：作者论证顺序、因果方向、研究假设、公式符号、实验数值、比较对象、显著性、不确定性和适用条件。原文疑似有错时先核对页面；确认疑点也应保留原文含义，并在单独说明中提出。

不把正文改成要点式提纲；不添加每节摘要、解读框或“核心创新”作为默认服务。若用户要求逐段讨论编号，可用 Word 书签或独立映射表，正文无需塞满来源标签。

## 合并与内容复核

并行翻译按稳定章节分工，重叠边界只用于上下文，不得重复写进成稿。合并后主审复核术语表、上一节/下一节指代、前后比较基线、图表公式引用和结论强度。

数字审计不能取代语义核对：相同数字放错行列仍然错误；“下降至”和“下降了”可能拥有完全相同的数字；变量 0 与字母 O、1 与 l、上标与普通字形在提取中可能混淆。每个警告需要回看原页，在工作记录里给出处理结果，不为消除警告而篡改正确译文。
