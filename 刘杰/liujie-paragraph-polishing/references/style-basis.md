# 风格依据与定制要求

本技能将句子组织、段落推进和证据表达整理为可独立使用的规则。使用时以当前稿和用户要求为依据。

## 导师稿体现的稳定写法

本技能将主体先行、问题递进和证据匹配的写法整理为独立规则：

- 研究对象先出现，紧接明确的动作或关系。
- 抽象陈述后用实际过程解释含义。
- 段首先说明本段在定义、检验或揭示什么。
- 后句承接前句对象，实验由尚存问题引出。
- 方法、结果和解释各自清楚，不堆成多层从句。
- 相关工作按能力与研究问题组织。
- 贡献先命名实质产出，再解释方法和证据。
- 不同评价终点分开解释，结论随证据范围而定。
- 结论回收研究缺口、方法起点、各层证据及综合认识。

不将原稿中偶有的冗长句、重复限制或语法不自然之处固化成规则。

## 本技能采用的写作约定

| 要求 | 本技能的执行含义 |
|---|---|
| 摘要不能只讲实验做了什么 | 必须讲清问题、方法及原理，再选主要证据 |
| 引言稍微全面 | 交代背景、已有能力、具体缺口和本文定位，不堆文献 |
| 动机只说问题，还要总结 | 排除本文解决方案和结果，末段收束研究问题 |
| 贡献要有分量 | 写清研究产出、原理、问题和证据，区分已有与新增 |
| 结论三段 | 问题与方法；主要实验结论；整体认识与紧接问题的下一步 |
| 正文保持章节结构 | 未授权重构时，只改句子、衔接与必要段内逻辑 |
| 每章总领句 | 开头说明研究问题和该章的实际任务，动词符合章节职能 |
| 删掉绕弯和纯防御句 | 删除无论证作用的冗余，保留改变科学判断的限定 |
| 减少防御性写作 | 执行 [直接陈述与证据边界](direct-evidence-writing.md) 六项要求和逐句检查，正文修订默认只给修改后的正文 |
| 保留老师已有好措辞 | 最小修改，不做无意义的全句换写 |
| 先引出图表再解释 | 保持阅读中的问题—图表证据—判断关系 |

结论三段和动机严格问题化是本技能的默认写作约定；用户当前要求与目标期刊规范优先。

## 原项目事实不作为通用规则

以下内容不会带入其他论文：

- SPECK或AES的具体方法、实验设备、数字、基线和安全性结论。
- 某个投稿版本的章节编号、图表数量或正文20页目标。
- 某篇未发表稿的删除决定，或某个期刊、会议的实时政策。
- 导师旧稿中已经被新实验更新的事实。

需要沿用这些限制时，以当前用户指令和当前论文为准。技能包不包含论文原文、导师批注原件、数据集或私人联系信息。
