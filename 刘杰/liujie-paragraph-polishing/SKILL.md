# 刘杰-段落润色.skill

将论文写成审稿人能够顺着问题、方法和证据读懂的英文。模仿的是导师的句子构建和论证过程，而不是机械复制句式，也不是把其他论文的技术贡献套过来。本技能已包含所需风格规则；使用时不需要原来的导师稿或历史对话。

## 先确定本轮范围

- 以用户指定的当前稿为事实来源。导师旧稿只提供写作参照，不能覆盖后来新增的实验或最新结论。
- 用户要求“只改句子”时，保留章节与小节架构、论证对象、图表顺序、公式、引用、实验设置及数值；只调整表达、句间衔接和必要的段内顺序。
- 用户要求重构某部分时，按该部分的功能重写，但不要借机改动其他部分。已确认且明确锁定的段落保持原文。
- 用户要求“先讨论／先记录，之后再替换”时，只交付提案并记录采用稿；未授权写回前不改正文。已授权修改的任务直接完成，不逐节索要确认。
- 不把本技能变成固定实验方案、投稿规则或安全性证明流程。某一项目的20页要求、禁用文献和章节编号，仅在当前任务明确沿用时生效。

## 核心写法

1. **让主体和主要动作尽早出现。**通常先说研究对象、方法、实验、结果或图表做了什么，再给必要的条件、原因和解释。主体先行不等于每句都用 We。
2. **一个句子承担一个主要动作。**拆开同时承载背景、目的、操作、数字和推论的长句；保留必要的比较、因果和让步关系，不切成没有衔接的短句串。
3. **一个段落解决一个问题。**段首先交代该段要定义、提出、检验或说明什么；后续句围绕同一对象推进。
4. **下一步由尚存问题引出。**说明前一个结果还不能区分什么，接着交代下一比较为什么必要。不要把整篇论文写成 First / Then / Finally 的实验日志。
5. **方法、证据和推论各司其职。**方法说明如何回答问题；结果给出关键比较；解释说明结果支持什么。三者可以相邻，但不要全部塞进一个句子。
6. **保留会改变结论含义的条件。**比较基线、样本或预算、评价终点、适用范围及不确定性不能为了简洁而消失。删除反复自我辩护、却不增加论证内容的句子。
7. **贡献的分量来自实质。**写清提出了什么、基于什么原理、解决了什么问题、证据说明了什么；不靠 novel、groundbreaking、comprehensive 等形容词拔高。
8. **先尊重已有好句。**明确要求保留导师措辞时，仅修复语法、逻辑、冗余、过时事实和必要衔接，不为了显示润色而全句换写。

## 减少防御性写作

每次起草或修订正文前，读取并执行 [直接陈述与证据边界](references/direct-evidence-writing.md)。直接陈述观点，用已有事实、推理和具体例子支撑；删除没有信息的自我辩护、预设反驳和模糊限定，保留影响结论的条件与不确定性。完成后逐句检查其事实、解释、比较或必要边界是否明确。

正文修订默认只输出修改后的正文；用户要求说明或对比稿时按其要求交付。文件任务仍提供文件链接，影响采用的实质事实问题须明确告知。

## 各部分的职责

实际修改前，阅读 [分部分写作规则](references/section-playbook.md) 中与本轮相关的部分。

| 部分 | 应完成的论证任务 |
|---|---|
| 摘要 | 现实问题及后果 → 本文研究目标 → 方法及核心原理 → 最有解释力的证据 → 回答了什么问题 |
| 引言 | 概念与背景 → 具体矛盾 → 已有工作的能力与边界 → 剩余问题 → 本文位置 |
| 动机 | 只写问题、为什么难、现有证据为什么不足；最后汇总核心研究问题，不介绍本文的方法、实验或结果 |
| 贡献 | 以可辨认的研究产出为中心，连接问题、方法、原理、证据和意义；区分已有、适配与新增内容 |
| 正文 | 保持既有章节架构，以直接句式讲清定义、方法、设计、结果和解释；每章或小节开头说明其任务 |
| 结论 | 默认三段：问题与方法；主要实验各自揭示的结论；整体认识、适用范围及紧接剩余问题的未来工作 |

全篇风格修订另读 [句子与段落范式](references/sentence-and-paragraph-patterns.md)。不要把范式逐条机械套用；先看该句实际承担的功能。

## 工作流程

1. **建立事实与范围清单。**阅读本轮涉及的完整上下文、相关图表和结论。记下允许改动的部分、锁定内容、关键术语、比较基线和主结论。发现实质矛盾时核对证据；证据不足则在编辑说明中提出，不臆造修复。
2. **对应问题、贡献和证据。**检查每个动机问题是否由某项贡献回应，每项贡献是否有正文支撑，摘要和结论是否与这些证据一致。不强行把所有论文凑成三个创新点。
3. **先修句子，再修衔接。**找出主语和核心动词，删除空壳表达，明确指代，把比较对象放在同一语法框架中。只在授权范围内合并重复内容或调整顺序。
4. **按章节职责精修。**避免在动机提前回答问题、把贡献写成实验清单、把讨论写成另一份结果清单，或在结论引入新发现。
5. **核对保护项和全文一致性。**依照 [修改与交付检查](references/revision-and-quality-checks.md) 核对数值、公式、引用、图表及推论强度；只检查确实相关的项目。
6. **交付完成稿。**用户要文件时修改文件、验证格式并给出链接；只要段落时直接给英文采用稿。默认不附修改说明；用户要求解释或对比稿时再按要求补充。影响采用的实质事实矛盾或未解决问题须明确告知。

## 页数、图表与声明

- 没有当前明确页数要求时，不自动压成20页。若要求20页，确认正文与参考文献的计数范围，在实际模板编译后核查；优先压缩获准修改的正文，尤其重复讨论。不得删必要证据、改数据或违规缩小字号来凑页数，也不写空话填满页面。
- 保留已有引言定位表和图表相对顺序；在正文先引出图表，再解释它支持的具体判断。图题简洁，完整术语、统计符号和必要定义仍须可查。
- 本轮允许处理版式且模板没有冲突要求时，表格默认采用水平、垂直居中；用户当前要求优先。纯文字修订不自动重排图表。
- 不在科研叙述中主动加入无关的AI使用说明。已有声明若涉及明确的投稿要求，不能按一般“去冗余”规则自动删除；遵守用户当前范围及实际要求。
- 本技能无需实时文献检索来完成纯语言修改。需要新增或更改文献、首创性或最新比较结论时，先核实来源；无法核实就不补写。

## 使用边界与风格依据

参照 [风格依据与定制要求](references/style-basis.md) 区分导师的可观察写法、用户的明确偏好和原项目特有限制。保持语言清楚与证据准确，不能将“高水平英文”误解为复杂句、形容词或结论拔高。

最终逐项问：**这句话的主体是谁？这段解决什么问题？这个实验消除什么歧义？这个结论由什么证据支持？**
