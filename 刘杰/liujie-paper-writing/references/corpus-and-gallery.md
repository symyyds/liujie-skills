# S1：文献、PDF 与分类图库

## 收录范围和完整性

1. 按用户给出的 venue、年份、论文类型和方向确定范围；区分 online-first、正式卷期、会议年份、录用目录和预印本。CHES/2021–2026 不作为默认常量。
2. 执行时联网核对官方目录、publisher proceedings/卷期及当期信息，保存访问日期。尚未公布或未结束年份只可称“截至某日已公布”，不能宣称全年所有。
3. “所有”以官方可核对目录为分母，不以搜索结果数量为分母。按 DOI、标题及版本去重，保留预印本/终稿关系和排除理由。
4. 建 corpus.csv：paper_id、标题、作者、venue、卷期/年份、类型、DOI、官方条目 URL、PDF URL、版本、访问日期、下载状态、本地路径、SHA-256、方向标签。
5. 获取可合法访问的全文；登录/付费/无全文的条目登记缺失及原因，必要时由用户提供。不绕过访问控制，不把网页打印件或摘要冒充 PDF 原稿。
6. 核对文件确为可打开的 PDF、页数正常、标题作者匹配；不能把登录 HTML 改后缀。以稳定 paper_id 命名。
7. 输出年度官方范围数、已取原稿数、缺失数、去重/排除数。不确定分母时明确“无法验证全集”。

## 研究方向归纳

采用可多选层次标签：对象、方法、任务、问题/威胁模型、数据/设备、指标、复现资源、贡献和局限。每项有论文与页码证据；全文阅读和仅摘要阅读分开。不用少数样本声称覆盖整个领域。

## 提取所有论文图

- 按全文逐页建立图清单，记录 Figure 编号、图注、页码、bounding box、子图、补充材料范围；表格是否另列在范围约定中说明。Logo/字形/装饰不算科学图。
- 单纯提取 embedded image 会漏矢量/路径/组合图。保留可提取原图，同时渲染 PDF 页面，按图注对应边界裁完整图；多面板保留全图及有用子图。
- 扫描 PDF 采用页面识别与裁剪；OCR 仅辅助。密集文字/公式/边界必须放大视觉核验，不能凭图像对象数宣称全部提取。
- 主类固定为用户要求的四类：**框架图、流程图、可视化图、其他图**。框架侧重模块关系，流程侧重顺序/控制，可视化侧重数值证据；允许次级标签及待复核，设备照片等放适当类别。
- figure-index.csv 记录 figure_id、paper_id、Figure编号、页、坐标、图注、主类/次类、提取方式、原图/预览路径、来源、许可、复核状态。
- 逐篇对账图号与提取清单，登记漏图、重复、裁断、无法判定项。仅抽样不能代替要求的全篇图号核对。

## 本地 HTML 图库

交付离线可打开的 index.html 和相对路径资源，包含四类导航、年份/论文/方向过滤、标题/图注搜索、缩略图放大。每图显示论文标题、venue/年份、图号/页码、图注摘要、PDF/官方入口。

提供覆盖率、缺失、待复核入口。对代表性好图解释可借鉴的信息层次、布局、比较逻辑、颜色语义、坐标/标注、子图组织和可读性；不把其科学内容移植成用户成果。

带来源的原图用于私人研究参考；公开发布前核查许可，不能把本阶段授权当成公开再分发整套论文和图片的授权。

实际核验 HTML 打开、过滤/搜索、图片加载、链接与图注；提取覆盖与人工复核覆盖分开报告。

## 验收

给出 corpus.csv、方向总结、PDF目录、figure-index.csv、HTML入口和漏项。使用实际数量；有缺口时请用户决定补齐或接受受限语料，不擅自把“所有”改成“部分”。
