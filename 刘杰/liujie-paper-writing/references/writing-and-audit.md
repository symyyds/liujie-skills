# S6–S7：结果驱动的写作、图示与审计

## S6：官方规范与写作依据

1. 按当前目标 venue/投稿轮次联网核实官方 author instructions、LaTeX模板、页数及附录/参考文献计数、匿名、图表规格、补充材料、数据/代码政策和所需声明。保存官方来源、访问时间与模板版本，不凭记忆套过期 CHES 规则。
2. 读取完整方案、写作要求 DOCX/PDF 和截图，提取 style-spec：字体、颜色、标线、坐标轴、子图、表线、误差表示及导出规格。按需用文档/PDF技能渲染核对，不能只取文字就声称参考过图片风格。
3. 建 claims-evidence.csv：claim_id、拟议陈述、限定条件、experiment/run/metric或文献证据、对应图表、核验状态。缺证据的只能是问题/假设，不写成发现。
4. 工作名和框架名醒目、简洁、准确；接口与可复用范围来自实际模块。不能在单一设备评估却声称全设备通用，不能夸大名称掩盖证据不足。

## 图表与结果表达

- 从保存的真实结果通过可复现脚本绘图；图、表、正文共用数值源。保存脚本、配置、作图数据、矢量/高分辨率导出，不手调曲线像素或编造“更好看”的点。
- 按论证选择折线、热力、柱状等可视化，匹配用户样式，不为凑图种虚构证据。
- 轨迹/信号研究默认含代表性原始轨迹图、轨迹质量分析图、真实设备或采集链路图；说明可复现的选样规则。其他领域用相应观测与质量证据，标明哪些类型不适用。
- 设备照片必须是真实设备；没有照片时请求补充或放明确标示的示意占位，不用生成图冒充实拍。
- 标清单位、样本/重复数、误差定义、变换、区间与 train/test 区别，披露筛选/排除。检查色盲/灰度可辨、裁剪/遮挡、图例、面板和论文内实际文字尺寸。

### 框架 pipeline 和深度学习 backbone

沿用默认路线时，两图先放可编译占位，不直接生成最终图；没有对应结构则标不适用，不能创造网络。实际读取 scientific-diagram-style-transfer 的 SKILL.md、prompt-template、style-spec 和必要的 transcription/topology 引用。

每图各给一份可直接复制的详细英文 prompt，包含：

- CONTENT SOURCE / TEMPLATE REFERENCE / SUPPORTING INPUT 的角色，科学内容与视觉风格分离。
- 实际模块名称、输入输出、已验证的张量形状、train/inference差异、损失/公式、分支/汇合/反馈/控制关系。
- 阅读方向、相对布局、图标语义、浅低饱和 Morandi 语义配色、Times New Roman（用户明确覆盖的除外）。
- 不可变拓扑、术语公式严格保真，不能增添未实现模块、连线或收益。

保存 terminology-and-topology.md 及 LaTeX label/图注。**实现与实验是事实源，prompt 是表达约定**：正文按相同模块和关系描述实际工作，不因 prompt 反向添加机制。用户替换图后逐项核对。

占位应有清晰的“待用户替换”状态、尺寸、图注和稳定引用，并在交付索引中登记。经用户约定的两图待替换可以交付，但含占位的 PDF 不能称为可直接投稿的终稿。

## 论文与文献

按目标领域和官方模板组织摘要、引言、相关工作、方法、实验设置、结果、消融、有效性威胁/局限、结论；不把 CHES 特定组织强加到其他学科。

以实测结果限定摘要贡献。正文必须包含 baseline 比较表并讨论公平性与缺口。消融应回答单因素作用，不用同时改多个变量的配置证明单模块贡献。

起草和修订正文前，读取并执行 [直接陈述与证据边界](direct-evidence-writing.md)；S7 逐句复核无信息的自我辩护、预设反驳和模糊限定，同时核对删改是否改变证据强度、适用范围或不确定性。

核实 .bib 的作者、标题、年份、DOI及正文关联；不用不可靠自动补全造引用。可调用适合的文献检索/学术写作技能，但除非用户要求，不把引文局限于 Nature/CNS，也不自动继承其目标期刊限制。

保留 LaTeX工程、bib、官方模板/样式、编译命令和日志。检查 undefined reference/citation、丢图、溢出、公式、页数与匿名；逐页渲染审阅最终 PDF。能编译不等于科学和版式通过。

## S7：四条审计链

### 数据—代码—运行—数值

核对数据哈希/划分、设备、版本/config/seed、原始输出、聚合脚本、图表数据和正文数字。回算关键指标，优先核摘要/结论/最优值；同时核全部登记数值的一致性。保留审计证据，不承诺程序检查能证明“全部真实”。

### 计划—实验—图表—主张

对原方案每个编号逐项核实现状、实现、结果、图表与主张。检查漏消融、混杂、统计单元、多重比较、不确定性、泄漏、选择性报告和不支撑的外推。不能补齐时降格结论，并取得用户对范围变更的确认。

### baseline—来源—可比性—正文位置

重新读取长表、原始证据和最终 PDF 比较表，核实数值、单位、方向、版本、协议、加粗/高亮及并列判定。必须能明确回答“baseline 结果对比在哪里”：给出表号、页/章节、数据与表格源码路径。仅列相关工作、只有表头、只有 Ours 都不算完成。

### 方法—提示词—图示—投稿规范

核对代码、提示词、图注、正文的模块/公式/符号/拓扑，框架复用声明不能超证据范围。核查官方模板、图表/字体/页数/匿名/参考文献/附录与声明。用户约定占位登记为例外，其他意外占位不得遗漏。

获准范围内修复并复核受影响证据链。新采集、大规模新跑、改协议/贡献需要退回相应阶段说明并申请，不能静默改范围。无法解决或核实的事实如实报告阻塞及最小补救路径，不宣称绝对无问题。

## 完整交付与最终回复

交付项目目录和文件索引，保留适用项的所有中间产物：

- 合法取得的原始 PDF、收录目录、方向总结、提取图及 HTML 图库。
- 原始实验方案、设备与数据审计、数据清单/版本、完整代码/依赖/环境、命令、配置、种子、运行日志、检查点、原始和汇总结果。
- baseline 来源、长表、正文表；图表数据/脚本/源文件/导出，两份图示 prompt 和占位替换说明。
- LaTeX工程、.bib、实际使用模板、编译 PDF/日志、逐页版式检查结果。
- 贡献实验覆盖矩阵、主张证据、真实性/逻辑/规范审计、失败与局限、复现指南、批准记录与交付清单。

许可或体积受限的数据保留真实位置、哈希、权限与获取方法；大数据/权重可索引，不必重复拷贝。不能默默删除中间文件或只交 PDF。检查索引路径可用、关键文件可读、比较表确已入文后给出明确入口并请用户验收。

最终回复必须点名 baseline 表号和路径，说明未完成实验、缺失比较与用户待替换图。投稿、上传公开仓库、联系作者/编辑另需用户授权，不属于本流程默认动作。
